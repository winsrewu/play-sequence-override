Bundled vectors are imported automatically on first run. Names such as BV1114y127ih.mp3 map to the internal id BBV1114y127ih. Entries whose track is not in the playlist are ignored. Use the folder picker to refresh C’s changed files.

OAuth allowlist

jawbts-gateway only redirects to hosts in src/config/allowlist.ts. Add this exact host, then rebuild the gateway. The embedding endpoint itself is not an OAuth redirect target and must not be added there.
