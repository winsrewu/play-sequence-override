OAuth2 / API

Cross-border data transfer

The URLs above are remote services. Using them sends request data — your IP address, the video id and your token — outside your country. Tick the box to consent; you can revoke it at any time. Without consent the extension will not sign in or fetch vectors automatically, and you can still import vectors from files.

Playback

Lyrics detection

FireRedVAD listens for vocals (singing or speech) in each track's audio on the embedding service; the service answers in batches, so detection runs for the whole library with one progress bar. While the share is on, a track without a verdict is never picked, so classify the library before relying on the pattern.

Playlist

Export the current library as a v2 JSON file, or import one.

Embedding data (C format)

Pick the folder that holds the C music_embed*.json files (a legacy data folder works too; other JSON such as music.json is skipped). Nothing is bundled and nothing is read from a data folder. Names such as BV1114y127ih.mp3 map to the internal id BBV1114y127ih. Entries whose track is not in the playlist are ignored.

Unavailable vectors

Tracks the embedding service reported as deleted or private. Automatic fetching skips them for 24 hours and retries afterwards.

    Vector backup

    Export every stored vector to a JSON file, or import a file produced by Export. Importing updates matching ids and keeps the rest.

    Lyrics backup

    Lyrics are exported as their own file, separate from the vector backup. Importing updates matching ids and keeps the rest.

    OAuth allowlist

    jawbts-gateway only redirects to hosts in src/config/allowlist.ts. Add this exact host, then rebuild the gateway. The embedding endpoint itself is not an OAuth redirect target and must not be added there.
